# 无猜扫雷

用 Edge 或 Chrome 打开 `index.html` 即可离线游玩。棋盘使用经典八邻域，默认 8 × 8；宽、高分别可设为 2–24 格，至少一边须达到 3 格。可调整参数，再点击“生成棋局”。雷数由生成器选择，生成后显示在棋盘上方。

## 操作

- 左键确认必安全格，右键、`Shift` + 左键或 `F` 确认必雷格。确认后先画红 `/` 或红 `X`；本轮所有必安全格和待标的必雷格都确认后，点击棋盘上方的“开格并插旗”。错点、错标或判定未完成时，不增加确认。
- 可从已开格拖出旗子，或拖动已有旗。有效落点先画红 `X`，随整轮提交后插旗；拖到可能安全的格时提示错误并保留原旗。右键点击已有旗，或将它拖到已开格或棋盘外，可撤旗。
- 点击已开的数字：红安全线按安全计，红叉和旗按待核验的雷位计。剩余雷数等于未确认的邻格数时补红叉；剩余雷数为零时补红安全线。候选格仍须通过公开局面的安全判定。右键点数字只尝试补红叉。
- 右下角灯泡展开推理工具，选择功能后菜单保持展开。“线索”高亮所用数字，“推导”在棋盘旁显示公式。“求解一步”只红标本组结论；再次点击可在原公开局面推导下一组。标齐后点“开格并插旗”。“自动求解”逐组画红标，标齐后自动开格插旗；中途停止会保留尚未提交的红标。“展示答案”标出当前所有必雷和必安全格，并随开格刷新。
- “重开本局”恢复生成棋局时的开局；“取消”停止正在进行的构造并保留当前棋局。

## 局面种子与编辑器

- 「导入种子」「导出种子」可在游戏和编辑器中使用。`MS1.` 保存实际雷位、已开格、旗标和双色记号。数字摆局使用 `MS2.`，只保存尺寸、公开数字、总雷数和标记，不含雷位，可导出尚有矛盾的草稿供继续编辑。
- 「标雷」用雷位决定八邻域数字；「标数字」填写总雷数，再选择 0–8 或橡皮擦，点击格子填入或盖回。也可以在格子上按数字键或 Delete。将数字局面导入游戏或点击「载入游戏」时，游戏以一张符合公开数字和总雷数的雷图开始，后续开格适用动态雷图规则。
- 「当前推理」显示当前局面的验证状态、待确认的必安全格和必雷格数量，以及已核验的最少线索数。「解法评级」单独显示技巧回放结果；整局卡住不影响显示当前的确定结论。导入的旗不作为证据，已独立证实的正确旗不用重复标记；撤旗后可重新推导并确认该格。蓝色记号不参与推理。
- 确认没有可判定格时，可点击「开扩」。系统按新增公开格数从少到多寻找能继续推理的一组安全格，只打开选中的格子，不自动展开零格。若不能证实最少开格数，保留原局面。

## 蓝色记号

点击右下角蓝色笔形按钮展开双圆弧记号。先选符号，再点格子；同一格的新蓝色记号会覆盖旧记号，重复点同一符号可擦除，也可右键擦除。点中央鼠标图标返回游玩，长按蓝色笔按钮清空蓝记号。本轮红色确认与蓝色笔记可以同格显示，清除蓝记号不会撤销红色确认。

| 层级 | 雷 | 安全 |
| --- | --- | --- |
| 第一层 | `x` 拟定、`o` 拟推 | `s` 拟定、`/` 拟推 |
| 第二层及以上 | `v` 拟定、`ʌ` 拟推 | `e` 拟定、`//` 拟推 |

`X` 沿格子的两条对角线绘制；同色相邻的 `/` 和同层 `//` 分别连成单线和成对曲线。首尾正交相邻时画成圆滑闭环。`+`、`−` 调整新记号的下标，已落记号不变。长按 `−` 只清除最高层的拟推记号。选笔后菜单收起，可以点任意棋格；按 Escape 或通过菜单中央的鼠标按钮退出画笔。记号模式下可使用棋盘上方的撤销、重做按钮。

## 无猜验证与动态雷图

当前局面的一张合法雷图必须同时满足所有已开数字和公开总雷数。开格裁判用递归约束搜索枚举合法布局并分类未知格：存在雷布局的格不能开；只有全部合法布局都判定为空的格才可开。若搜索未完成，裁判不把“尚未发现反例”误当成安全结论。

打开必安全格后，游戏可在旧线索覆盖范围外调整雷位。新雷图保留全部旧数字、已开格安全性和总雷数，并须通过逐步核验最少线索的技巧通关检查。调整方案无法通过校验时保留原雷图；手动确认的安全格仍可整批打开。

## 生成与难度

生成器用种子选择安全线索的交叠形状。小棋盘使用更紧凑的交叠形状，也可从一个安全格开始，逐步增加安全线索。局部雷位按线索加减后的系数排布，使合成式达到极值或只离极值一格权重；相消的格子可以变化。增补安全线索时保持原有数字不变。

峰值线索下限达到 6 且棋盘两边各至少 5 格时，部分轮次优先尝试满足峰值下限的最短偶数闭环，也探索更长的环。相邻线索共享的未开格在交替加减时相消。每段交集同时留有雷和安全格，减少拆环后出现短解的机会。环外的独占格按合成等式的极值布置。开局仍须验证整个局面的最少线索数，完整技巧回放决定是否达到整局难度下限。

开局确定后，按每组最少线索推出的安全格和必雷格构造续局。默认 8 × 8 和其他高难配置会尝试更大的线索交叠、更多种雷密度，以及在同受一组公开数字约束的未判定格之间交换雷位。交换不改变旧数字和总雷数，却能改变下一批打开格子的数字。发放和评级按实玩规则回放：每步只红标，标齐本轮才开格插旗；只打开确认过的格子，零格不会自动展开。若不能用技巧标齐整轮，该局不通过认证。

“难度设置”的三个下限必须同时达标。每项留空时使用输入框显示的默认值。8 × 8 默认是平均最少线索 **2**、多线索步骤占比 **30%**、峰值线索数 **6**。其他尺寸的默认值为平均最少线索 **1.2**、峰值线索数 **2**；多线索步骤占比在任一边短于 5 格时为 **0%**，否则超过 64 格时为 **5%**，其余为 **10%**。占比输入 `20` 表示至少 20% 的步骤需要三条或更多线索，输入 `0` 不设占比限制。

生成在后台持续搜索，找到第一局通过完整技巧回放且三项达标的棋局即停止。搜索进度会显示已搜索轮数及最接近目标的候选评级。极高的下限可能始终找不到达标局，可点击“取消”停止并保留当前棋局。

每次点击“生成棋局”时，浏览器从加密随机源抽取生成种子。生成进度和棋盘上方显示种子；要分享或恢复棋局，请导出局面种子。

| 评级 | 含义 |
| --- | --- |
| 首步最少线索 | 在开局推出任意一个必安全格或必雷格所需的最少线索数。单个数字和总雷数各计一条。 |
| 首步推导深度 | 第一项技巧证明链的深度；直接数数为 0，双区减法为 1，复合不等式按组合链计深。 |
| 开局反证深度 | 对开局中可判定的格子逐格反设，记录每次排除反设所进入的最深分支。显示各格深度的最小值至最大值。 |
| 高级卡点 | 数数与双区减法都无步可走，必须转用高级推导的连续阶段数。 |
| 峰值线索数 | 整局每步的最少线索数取最大值。设置下限为 4，表示至少有一步确实需要 4 条或更多线索。 |
| 平均最少线索 | 每个步骤经核验的最少线索数的平均值。 |
| 平均枚举深度 | 每步用当时的公开数字、总雷数和已证实的雷做递归反证；取该步推出的各格中最浅的反证深度，再对全局步骤等权取平均。无分支即证矛盾记 0。深度与搜索顺序有关，仅供诊断；未测全局时不显示数值。 |
| 多线索步骤占比 | 最少需要三条或更多线索的步骤，占全部步骤的比例。同一组线索得出的安全格和必雷格合计一步；连续双区减法的每一步仍只算两条。 |

达标的棋局优先比较平均最少线索数，其次比较多线索步骤占比和分布。评级对应一条已验证的技巧路径。玩家开格顺序和动态雷图可能令实际过程不同。

## 求解技巧与证明

- **数数**：区域剩余雷数为 0 时全部安全；等于未知格数时全部为雷。
- **双区减法**：把两个线索区拆成独有部分和交集，利用各区域容量分别求雷数上下界，再传递到目标区域。
- **加权相消**：将线索等式加减以消去共同变量；再用二元变量的取值范围判断剩余项是否迫使目标格取定值。
- **整数割**：对 `Σ aᵢxᵢ ≤ b` 且 `xᵢ ∈ {0,1}`，可推出 `Σ ⌊aᵢ/2⌋xᵢ ≤ ⌊b/2⌋`，再把新界与其他不等式合并。
- **逐格相消**：把区域雷数上下界化成至少一项成立的文字，消去相反标记的共同格，直到得到单格结论。

证明连续列出公式，来源紧跟式后。原始线索及它们的加减都是等式。取界和整数割引入的不等号保持原样；若上下界相同，或上界恰好为 0 且雷数非负，再单列等式。右端是负常数时，两边取反并交换位置，例如 `E ≤ −2` 显示为 `2 ≤ −E`。圈住的坐标表示该数字的邻域中计入本式的格子，已证雷的扣除量标在式后。等价格可合并为组合变量；完整行、列和矩形分别用行号、列名及对角坐标表示。

连续加减合写一式；取界和取整的结果各用独立的不等式，达到极值后再列等式结论。同一合并式的极值界只列一次。将鼠标悬停在式后的「相消」，或用键盘聚焦该按钮，棋盘上灰纹表示正负覆盖抵消的格，蓝色和橙色分别表示相消后还留在正项和负项的格。点击可暂留或关闭标色。

本步结论将安全格与必雷格分别合并为区域。矩形可跨过已开格，但不会包含不属于该区域的未开格。悬停或聚焦区域标签时，只高亮实际计入公式或属于结论的格子。

每步在所有尚未判定的格子中比较线索数，每个数字和公开总雷数各算一条。先用一条技巧证明给出上界，再用目标格取反时的可行布局排除所有更小的线索组合。该证明选定的线索同时推出安全格和必雷格时，两类结论都纳入同一步。此前已证明的雷可作为已知条件，手插旗不能。递归只用于内部核验和安全判定，展示的是不等式推导。生成器只发放通过首步最少性及批量技巧通关验证的棋局；校验失败会舍弃候选，不给未证明的评级。

延伸阅读：《巧克力攻略(清晰版)》第 9–15 页介绍数数、减法、连续减法、不等式和总雷数；《扫雷解局学2024版》介绍多集合关系与区域雷数上下界。
