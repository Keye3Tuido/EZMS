# 无猜扫雷EZMS

用 Edge 或 Chrome 打开 `index.html` 即可离线游玩。棋盘使用经典八邻域，默认 5 × 5。可调整参数，再点击“生成棋局”。雷数由生成器选择，生成后显示在棋盘上方。

## 界面布局

显示或收起辅助信息时，已显示的棋盘、控件和指标尽量保持原位。临时选项优先浮层呈现，进度与操作入口预留位置；较长内容在自身区域滚动。玩家主动跳转、调整窗口或更改棋盘尺寸时，布局随操作更新。

桌面端在棋盘右侧切换「当前推理」和「推导」，折叠侧栏可为棋盘腾出空间。手机端的「当前推理」位于棋盘下方，用上下箭头独立开合；推导在可滚动的浮窗中显示，用 `×` 关闭，不替换指标。短横屏的推导浮窗为右侧推理按钮留出空间。

游戏全屏仅在电脑端提供。点击标题栏的全屏图标进入，再点一次退出，棋局和标记会保留。浏览器不支持或拒绝全屏时，游戏会提示已切换到网页内模式，此时浏览器栏仍可能可见。

本页默认播放动画。点击标题栏的「动画效果」图标可关闭菜单和棋格动效，长按进度圈仍显示；再次点击恢复动画。此选择保存在浏览器中，只影响本游戏。

## 操作

- 左键确认必安全格，右键、`Shift` + 左键或 `F` 确认必雷格。确认后先画红 `/` 或红 `X`，棋盘下方显示本轮进度。标齐后点击“开格并插旗”：红标退场，安全格显示数字，必雷格落旗。错点或错标会在对应格提示，进度不变。
- 可从已开格拖出旗子，或拖动已有旗。有效落点先画红 `X`，随整轮提交后插旗；拖到可能安全的格时提示错误并保留原旗。右键点击已有旗，或将它拖到已开格或棋盘外，可撤旗。
- 点击已开的数字：红安全线按安全计，红叉和旗按待核验的雷位计。剩余雷数等于未确认的邻格数时补红叉；剩余雷数为零时补红安全线。候选格仍须通过公开局面的安全判定。右键点数字只尝试补红叉。
- 右下角灯泡展开推理工具，选择功能后菜单保持展开。“线索”高亮所用数字，“推导”在棋盘旁显示公式。“求解一步”只红标本组结论；再次点击可在原公开局面推导下一组。标齐后点“求解一步”或“开格并插旗”提交整批。“自动求解”逐组画红标，标齐后自动开格插旗；中途停止会保留尚未提交的红标。“展示答案”标出当前所有必雷和必安全格，并随开格刷新。
- 蓝色记号笔、选区和推理工具由各自主按钮展开。蓝色记号沿圆弧环绕主按钮，选区的四个按钮由一段短圆弧串联。再次点主按钮可收起。选区菜单选择“增加选区”或“减去选区”后，点未开格选单格，点数字选它周围尚未确定的格子。正系数用紫色，负系数用黄色。重叠处按系数相加，结果为零时移除高亮。棋盘下方分三行显示选区、加权雷数和线索剩余。悬停选区中的一项会突出对应区域，悬停线索坐标会突出对应的棋盘数字。收起后退出选区工具并保留预览。菜单中的撤销和重做逐步恢复增减和长按清空的结果，撤销后做出新选区会清除可重做的步骤。切换画笔、操作棋盘或进出局面编辑器时，会保留原棋局的选区。手动清空或打开提示功能时才清除。
- “重开本局”恢复生成棋局时的开局；“取消”停止搜索并保留当前棋局。有候选后，搜索进度旁会显示“停止并采用候选”。
- 鼠标悬停在公式行上会高亮该行和棋盘上的正、负系数区域；悬停在公式元素上则用蓝色显示它对应的格子。触屏上点按行或元素可保留高亮，再点同一处或点公式外可清除。
- 反馈音效默认开启，从首次操作开始播放。按钮、棋格、落笔、擦除、标齐、提交、误操作和通关有对应的声音。点顶栏扬声器可静音；浏览器允许保存偏好时，刷新后仍保持所选状态。

## 局面种子与编辑器

- 游戏和编辑器只接受当前格式的无前缀 Base92 局面种子。种子保存棋盘尺寸、已开安全格、旗子和未开格上的红标，包括尚未提交的红色确认。导入和导出时忽略已开格上的红标。标雷局面另存雷位；标数字局面保存总雷数和公开数字，也可保存有矛盾的草稿。普通蓝标和绿色持久标均不随种子导出或导入。
- 「标雷」用雷位决定八邻域数字；「标数字」填写总雷数，再选择 0–8 或橡皮擦，点击格子填入或盖回。也可以在格子上按数字键或 Delete。将数字局面导入游戏或点击「载入游戏」时，游戏以一张符合公开数字和总雷数的雷图开始，后续开格适用动态雷图规则。
- 「当前推理」默认显示所有可推理步骤中的最少线索数。点击「线索」或「推导」会按当前局面选出一步，并显示这一步的最少线索数。已核对的红叉按有雷、红线按安全代入，不另计线索数。每轮可按任意顺序确认，棋盘下方保留本轮进度。标齐后可开格并插旗。
- 「余局平均线索」从当前公开数字和已确认红标出发，取无猜通关解法中各剩余推导步骤的最少线索数的平均值。未验证通关或已无推导步骤时显示「—」。数字摆局的通关验证基于一张符合公开线索的雷图。
- 「本局峰值最少线索数」取初始盘面无猜通关回放中各步最少线索数的最大值；「本局多线索推理占比」取其中最少需要 3 条或更多线索的步骤占比。两项与生成筛选同口径，游玩期间保持不变，编辑盘面后重新计算。没有完整通关回放或没有推导步骤时显示「—」。
- 编辑器中的旗和红标是可随草稿保存的标记，不改变雷位或数字。右下角的红笔提供红 `x` 和红 `/`。再次点击主按钮返回编辑。点按或拖动画笔可标记、擦除和覆盖，右键擦除单格，长按笔清空红标；每笔及清空都可撤销和重做。红笔和蓝笔都跳过已打开的格子，包括 0。
- 编辑器在「载入游戏」旁显示草稿标记校验，独立于棋局的无猜验证。旗和红叉必须能由公开数字及总雷数证实为必雷，红斜杠必须能证实为必安全。与线索冲突或尚不能证实的标记会提示坐标，且不能从编辑器载入游戏或在游戏中导入。核验通过后，旗作已知雷，未提交的红标恢复确认进度；与已插旗重复的正确红叉不再显示。
- 确认没有可判定格时，可点击「开扩」。系统按新增公开格数从少到多寻找能继续推理的一组安全格；选中格若为零，会自动展开相邻空白及边界数字。若不能证实最少开格数，保留原局面。

## 蓝色记号

点击右下角蓝笔展开圆弧记号。选符号后可点按，也可按住扫过多个格子。起笔格已有同符号、同层级的普通蓝标时，整笔擦除经过的普通蓝标；否则整笔写入并覆盖原有普通蓝标。右键可擦除单格的普通蓝标，点中央鼠标图标返回游玩。

长按 `+` 取交集，然后清空普通蓝标。所有层级的拟定、拟推都参与：雷用深绿色小圆圈 `o`，安全用深绿色小斜杠 `/`。棋盘没有绿标时，用当前蓝标建立绿标；已有绿标时，同向保留、反向清除，没有蓝标的绿标原样保留，也不会在原本没有绿标的格子新增。绿标贴近格内顶边，水平居于距左边四分之一格宽处，可与普通蓝标共存。

长按 `−` 清除第二层拟推；画笔层级高于第二层时，清除棋盘上的最高层拟推。拟定标记保留。

长按蓝笔优先清空普通蓝标；没有普通蓝标时，才清空绿色持久标。棋盘顶部的撤销和重做按操作顺序处理每笔蓝标、持久化、清理及本轮红色确认。开格插旗后，本轮红标从历史中移除。

| 层级 | 雷 | 安全 |
| --- | --- | --- |
| 第一层 | `x` 拟定、`o` 拟推 | `s` 拟定、`/` 拟推 |
| 第二层及以上 | `v` 拟定、`ʌ` 拟推 | `e` 拟定、`//` 拟推 |

`X` 沿格子的两条对角线绘制；同色相邻的 `/` 和同层 `//` 分别连成单线和成对曲线。首尾正交相邻时画成圆滑闭环。`+`、`−` 调整新记号的层级，已落记号不变。第二层不显示下标，第三层起显示。长按 `−` 时，层级为 2 则清除第二层的 `ʌ` 和 `//`，层级更高则清除棋盘上最高层的拟推记号；拟定记号保留。选笔后菜单保持展开，可继续换笔或点击棋格落笔；按 Escape 或再次点击主按钮退出画笔。记号模式下可使用棋盘上方的撤销、重做按钮。

## 无猜验证与动态雷图

当前局面的一张合法雷图必须同时满足所有已开数字和公开总雷数。开格裁判用递归约束搜索枚举合法布局并分类未知格：存在雷布局的格不能开；只有全部合法布局都判定为空的格才可开。若搜索未完成，裁判不把“尚未发现反例”误当成安全结论。

打开必安全格后，游戏可在旧线索覆盖范围外调整雷位。新雷图保留全部旧数字、已开格安全性和总雷数，并须通过逐步核验最少线索的技巧通关检查。调整方案无法通过校验时保留原雷图；手动确认的安全格仍可整批打开。

## 生成与难度

生成器用种子选择安全线索的交叠形状。小棋盘使用更紧凑的交叠形状，也可从一个安全格开始，逐步增加安全线索。局部雷位按线索加减后的系数排布，使合成式达到极值或只离极值一格权重；相消的格子可以变化。增补安全线索时保持原有数字不变。

峰值线索下限达到 6 且棋盘两边各至少 5 格时，部分轮次优先尝试满足峰值下限的最短偶数闭环，也探索更长的环。相邻线索共享的未开格在交替加减时相消。每段交集同时留有雷和安全格，减少拆环后出现短解的机会。环外的独占格按合成等式的极值布置。开局仍须验证整个局面的最少线索数，完整技巧回放决定是否达到整局难度下限。

5 × 5 的峰值下限为 10 或 11 时，生成器还会把公开总雷数和多个交叠数字一起相消。种子决定线索形状和相消格的布置，同一轮可以先有较短的推导，再遇到必须使用更多线索的格子。

增量构造续局时，可在同受一组公开数字约束的未判定格之间交换雷位。交换不改变旧数字和总雷数，却能改变下一批打开格子的数字。无猜验证按实玩规则回放：每步只红标，标齐本轮才开格插旗；打开零格时自动揭示相邻格，这些自动揭示不计作推理步骤。若不能用技巧标齐整轮，该局不通过验证。

“难度设置”的三个下限必须同时达标。生成筛选、最近候选和游戏内统计采用相同规则：已确认红叉和红线作为已知条件，不另计线索。任何尺寸下，留空都采用相同默认值：平均最少线索 **2**、多线索步骤占比 **30%**、峰值线索数 **5**。各项可独立调整，占比填 `0` 可取消这一项限制。宽高填写正整数；大棋盘受浏览器资源和计算成本限制。可编辑的尺寸不保证能构造出达到所选难度的棋局。

生成在后台持续搜索，找到第一局通过完整技巧回放且三项达标的棋局即停止。搜索进度显示轮数、通过技巧验证的候选数，以及最接近候选的三项实测值和未达标项。候选只要有一局峰值未达标，就优先取实际峰值较高的棋局。两局峰值都达标时，优先取多线索步骤实际占比较高的棋局。优先指标相同时，再比较三项的相对差距总和。点击“停止并采用候选”会载入当前最接近的候选，状态栏仍显示未达标项。

每次点击“生成棋局”时，浏览器从加密随机源抽取内部生成种子。要分享或恢复棋局，请导出局面种子。

| 生成条件 | 含义 |
| --- | --- |
| 峰值线索数 | 整局每步的最少线索数取最大值。设置下限为 4，表示至少有一步确实需要 4 条或更多线索。 |
| 平均最少线索 | 每个步骤经核验的最少线索数的平均值。 |
| 多线索步骤占比 | 最少需要三条或更多线索的步骤，占全部步骤的比例。同一组线索得出的安全格和必雷格合计一步；连续双区减法的每一步仍只算两条。 |

## 求解技巧与证明

- **数数**：区域剩余雷数为 0 时全部安全；等于未知格数时全部为雷。
- **双区减法**：把两个线索区拆成独有部分和交集，利用各区域容量分别求雷数上下界，再传递到目标区域。
- **加权相消**：将线索等式加减以消去共同变量；再用二元变量的取值范围判断剩余项是否迫使目标格取定值。
- **整数割**：对 `Σ aᵢxᵢ ≤ b` 且 `xᵢ ∈ {0,1}`，可推出 `Σ ⌊aᵢ/2⌋xᵢ ≤ ⌊b/2⌋`，再把新界与其他不等式合并。
- **逐格相消**：把区域雷数上下界化成至少一项成立的文字，消去相反标记的共同格，直到得到单格结论。

证明连续列出公式，来源紧跟式后。原始线索及它们的加减都是等式。取界和整数割引入的不等号保持原样。右端是负常数时，两边取反并交换位置，例如 `E ≤ −2` 显示为 `2 ≤ −E`。圈住的坐标表示该数字的邻域中计入本式的格子，已证雷的扣除量标在式后。等价格可合并为组合变量；完整行、列和矩形分别用行号、列名及对角坐标表示。

连续加减合写一式；作为后续依据的取界和取整结果各用独立的公式。公式一旦确定新的安全格或必雷格，就直接高亮；同一式能推出两类结论时同时高亮。同一批推理只保留新增结论和所需的前提。悬停在等式或不等式所在行时，紫色表示正项、黄色表示负项；悬停或聚焦「相消」时，还会以灰色标出已相消的格子。点击「相消」可暂留或关闭标色。

本步结论将安全格与必雷格分别合并为区域。矩形可跨过已开格，但不会包含不属于该区域的未开格。悬停或聚焦区域标签时，只在实际计入公式或属于结论的格子上显示蓝色轮廓和绿色斜线。显示答案或推导时，安全格和必雷格分别使用绿、红底色和同色阴影。

每步在所有尚未判定的格子中比较线索数，每个数字和公开总雷数各算一条。先用一条技巧证明给出上界，再用目标格取反时的可行布局排除所有更小的线索组合。该证明选定的线索同时推出安全格和必雷格时，两类结论都纳入同一步。此前已证明的雷可作为已知条件，手插旗不能。递归只用于内部核验和安全判定，展示的是不等式推导。生成器只发放通过首步最少性及批量技巧通关验证的棋局。

延伸阅读：《巧克力攻略(清晰版)》第 9–15 页介绍数数、减法、连续减法、不等式和总雷数；《扫雷解局学2024版》介绍多集合关系与区域雷数上下界。
